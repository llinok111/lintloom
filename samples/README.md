# 样例说明（只读演示）

这些 SQL 由本项目自写，用于演示诊断 / 修复 / 语法树，**不含上游测试夹具**。

| 文件 | 特点 | 预期（ansi 方言，全规则） |
|---|---|---|
| `messy_orders.sql` | 单行挤在一起、隐式别名、`<>` 与 `>` 无空格 | 14 项违规：`LT09`（select 目标换行）、`AL01`（隐式别名）、`LT01`（空格）、`AM05/AM06`（隐式 join / 显式 join 混用） |
| `warehouse/dim_customer.sql` | 大写关键字、隐式别名、`WHERE` 未换行 | 3 项：`LT09`、`AL01`、`LT14` |
| `warehouse/fct_orders.sql` | 长单行、隐式别名、`ORDER BY` 未换行 | 6 项：`LT05`（行太长）、`LT09`、`LT01`、`AL01`、`LT14` |
| `broken.sql` | 末尾多逗号 + `where o.status =` 断句 | `PRS`（解析失败，不可自动修复）+ `CV03` + `AL01` —— 用来演示「解析失败」诊断 |

小提示：

- `messy_orders.sql` 的修复效果最直观：14 项里除 1 项外全部可自动修复。
- 想验证「修复后再复核」，对这个文件点「修复预览」，差异页头部会显示「复核剩余 N 项」。
- 想验证写回，请把文件复制到 `workspace/`（可写区），不要直接改 `samples/`。
